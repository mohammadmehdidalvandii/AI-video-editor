# Use Cases Context

## Purpose

This document defines the primary user interactions and workflows
supported by the AI Video Editor.

Use cases describe what users want to accomplish with the product,
without defining how the functionality is implemented.

---

# Core Use Cases

The initial product is organized around the following workflows:

1. Create Project
2. Upload Media
3. Analyze Media
4. Manage Media
5. Create Timeline
6. Edit Video
7. Edit Audio
8. Add Subtitles
9. Use AI Editing
10. Preview Changes
11. Render Video
12. Export Video
